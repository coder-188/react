# Simple Interest Calculator

A simple calculator application that computes simple interest based on user input for principal, annual rate of interest, and time period.

## Formula
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

Where:
- **P** = Principal amount
- **T** = Time period (in years)
- **R** = Annual rate of interest (%)

## Usage
Run the `simple-interest.sh` script in your terminal and provide the requested inputs when prompted.
